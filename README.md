## 📖 项目概览

基于 Node.js 构建的智能选课系统解决方案，提供 WebUI 界面和高效缓存机制，支持多轮次选课操作。

## ✨ 核心特性

- 🚀 **WebUI 交互界面**（Node.js + Axios + Vue3 + Express + WebSocket）
- 🔒 **登录信息与选课缓存智能管理**
- 🛡️ **多级别异常处理与防呆设计**
- 📦 **模块化架构设计**
- ⚡ **请求优化**（降低 90% 网络请求量）
- ⚡ **引入缓存和响应拦截器设置，最小化请求**

## 🚀 快速开始

### 环境要求

- Node.js 16+
- Chrome 100+

### 安装步骤

```bash
# 克隆仓库
git clone https://github.com/ZYYO666/fuck-shuwei.git

# 安装依赖
npm install

# 启动服务
npm start
```

### 打包单文件exe步骤

```bash
npm run build:win

```

产物在dist/index.exe

将public目录复制到dist（过程我也不知道那里的问题，静态资源无法被打爆在内部）

### 使用说明

1. 访问 `http://localhost:3000`
2. 按住 Ctrl + 单击进入管理界面
3. 配置选课参数
4. 实时查看 WebSocket 日志
5. 查看运行结果
